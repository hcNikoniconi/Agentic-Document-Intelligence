# Examples

This folder contains sanitized examples only.

The examples are not generated from real applicant documents. They are hand-written mock outputs that show the expected shape of the v2 pipeline artifacts without exposing private candidate data.

Use them to understand:

- what field-level evidence looks like;
- how the final candidate result is structured;
- how verification reports conflicts and source consistency;
- what a human-readable summary report should communicate.

Real candidate files and real extraction outputs should stay local and should not be committed.
